# Security Policy

## Supported versions

| Version | Security updates |
| --- | --- |
| Promise 3.x | Supported |
| Earlier versions | Not supported |

## Reporting a vulnerability

Please report vulnerabilities privately through the repository's **Security** tab using **Report a vulnerability**. Do not disclose suspected vulnerabilities in a public issue.

Include the affected version, the steps needed to reproduce the issue, and its impact. Do not include real message contents, account credentials, OAuth tokens, encryption keys, or personal data in a report.
